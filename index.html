How to Use

  1. Configure Streamer.bot WebSocket server (Settings → WebSocket Server)
  2. Set up Streamer.bot actions to send queue updates
  3. Add Player URL to OBS as a Browser Source
  4. Add Queue URL to OBS as a Browser Source
  5. Use chat commands (!sr, !queue, !song, !skip) to test
💡 Streamer.bot Setup: The Queue URL now includes WebSocket connection parameters. Make sure Streamer.bot is running with WebSocket Server enabled on the configured host/port.
